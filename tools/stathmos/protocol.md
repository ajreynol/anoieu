# The report card protocol

**Five rules decide how [`../../docs/report-card.md`](../../docs/report-card.md)
is updated, and none of them is new.** They were spread across four documents,
collected into one, and moved here when this project took the role — which is
what this ecosystem does with a description once something owns its subject.

| the question | the answer | where the rule comes from |
| --- | --- | --- |
| who may change a paragraph | **a person, asked first** | the supervision ladder in [`../../docs/coherence.md`](../../docs/coherence.md) |
| what is it graded against | **a fixed, recorded version of each project — never whatever is on their disk today.** Changing which version is a separate decision, because it changes what the build measures | the report card |
| which voice does a paragraph use | whichever that project's own maintenance note asks for: **people get an observation, agents get an instruction** | the report card |
| what shape does a paragraph take | *arete*, *elleipsis*, *parainesis* — **all three** | the report card |
| who may appear on it at all | tools in the inventory. **A child project may not**, until a person decides it has earned a place | [`../../docs/vision.md`](../../docs/vision.md) |

## The order, and the one trap

**Evidence first, judgement second, and never the same file.** Assemble what a
tool weighs — [`evidence.md`](evidence.md) — then write the paragraph. A
paragraph drafted before the evidence is a recollection with a citation added
afterwards, which reads identically and is worth nothing.

**Then check the recorded version already covers the work you want to credit.**
If it does not, updating it is the first act and a separate decision.

**The trap:** praising something the recorded version does not cover is grading
work the evidence does not contain. It reads as generosity and is the page
failing its own standard.

**And the check that matters more than the rest:** anoieu is graded on the same
scale, in the sharper register, and does not come out best.
